# Dream Forge

Dream Forge 可將一張清晰的物件參考照片轉換成 3D 模型。使用者可以選擇風格與帳戶可用的生成服務、產生輔助視角與網格、在瀏覽器中檢查結果，並下載目前提供的 GLB 檔案。實體列印訂購與付費點數加值仍在規劃中。

## Agent 入口

- 開始建立模型：<https://dreamforge.app/zh-TW/generate/>
- 登入：<https://dreamforge.app/zh-TW/auth/>
- API 文件：<https://dreamforge.app/docs/api/>
- OpenAPI：<https://dreamforge.app/.well-known/openapi.json>
