# Dream Forge

Dream Forge turns photos into textured 3D models. Use the web app to upload images, select a style and generation provider, create a mesh, preview the result, and export files for digital use or 3D printing.

## Agent Entry Points

- Start creating: <https://dreamforge.app/en/generate/>
- Sign in: <https://dreamforge.app/en/auth/>
- API docs: <https://dreamforge.app/docs/api/>
- OpenAPI: <https://dreamforge.app/.well-known/openapi.json>
